# LaporIn API

LaporIn API is a RESTful backend service built with Laravel for handling reporting and complaint management.

## Features
- User authentication
- Report management (CRUD)
- Status tracking
- REST API ready for frontend (Vue.js)

## Tech Stack
- Laravel
- MySQL
- REST API
